1. Database Schema Overview

This document details the enterprise database architecture and relational 3NF schema specifications for the Kundli AI platform. The system uses a production-ready, highly normalized PostgreSQL (Supabase) relational design, managed via SQLAlchemy 2.0 ORM and Alembic for migrations.

Key Architectural Directives

  • Authentication Boundary: Firebase handles secure authentication workflows, JWT verification, and credential protection. PostgreSQL maintains user profiles and local identity mapping linked via firebase_uid.
  • Vedic Precision Computations: Horizontal scaling for custom ephemeris charts is optimized via kundlis, planet_positions, houses, and dasha_periods tables.
  • Normal Forms (3NF): Normalized to 3rd Normal Form to minimize redundancy, leveraging junction tables (e.g. role_permissions, user_roles) and explicit indexes to optimize joins.
  • JSONB Support: Structured PostgreSQL JSONB datatype is leveraged for highly complex, multi-dimensional astrological matrices (e.g., panchang variables and raw payloads) where indexing is necessary but strict columnar formatting is suboptimal.

3. Identity & Role-Based Access Control (RBAC) Module

Manages user profiles, role assignments, and capabilities. Permissions enable granular security constraints enforced via FastAPI dependecy-injections and PostgreSQL Row Level Security (RLS) layers.

Table: users

Core user accounts containing application identity details associated with Firebase authentication.

Column Type Keys / Constraints Description
id UUID PK DEFAULT gen_random_uuid() Internal unique identifier for the user. Used for relational foreign keys.
firebase_uid VARCHAR(128) UQ NN External Firebase user UID mapping credential profile to authentication events.
email VARCHAR(255) UQ NN Email address of the user.
phone VARCHAR(32) Optional phone number.
display_name VARCHAR(128) Full display name of the user.
photo_url TEXT Avatar image URL.
preferred_language VARCHAR(10) DEFAULT 'en' User locale selection for notifications and reporting.
country VARCHAR(3) DEFAULT 'IND' ISO alpha-3 country designation code.
timezone VARCHAR(64) DEFAULT 'Asia/Kolkata' User default timezone string.
last_login_at TIMESTAMPTZ Timestamp tracking the user's last login session.
email_verified BOOLEAN DEFAULT FALSE Boolean showing if user verified their email on Firebase.
status user_status_enum NN DEFAULT 'active' Status flag: active, suspended, deactivated, deleted.
created_at TIMESTAMPTZ NN DEFAULT CURRENT_TIMESTAMP Record creation timestamp.
updated_at TIMESTAMPTZ NN DEFAULT CURRENT_TIMESTAMP Record modification timestamp.
deleted_at TIMESTAMPTZ Soft delete timestamp. If populated, user account is flagged as inactive.

Table: roles

Access roles governing general service configurations (e.g. Admin, Support, Registered User, Pro User).

Column Type Keys / Constraints Description
id UUID PK DEFAULT gen_random_uuid() Unique role identifier.
name VARCHAR(50) UQ NN Standard role name (e.g., 'admin', 'user', 'astrologer', 'support').
description TEXT Description explaining permissions granted under this role.
created_at TIMESTAMPTZ NN DEFAULT CURRENT_TIMESTAMP Timestamp when the role was created.

Table: permissions

Fine-grained application operations that can be assigned to different system roles.

Column Type Keys / Constraints Description
id UUID PK DEFAULT gen_random_uuid() Unique permission identifier.
code VARCHAR(100) UQ NN System string descriptor (e.g., 'generate_kundli', 'chat_ai', 'generate_report_pro').
description TEXT Plain text explanation of what security scope is permitted.
created_at TIMESTAMPTZ NN DEFAULT CURRENT_TIMESTAMP Record creation timestamp.

Table: role_permissions

Junction table facilitating a many-to-many relationship between system roles and system permissions.

Column Type Keys / Constraints Description
role_id UUID PK FK REFERENCES roles(id) ON DELETE CASCADE Target role identifier.
permission_id UUID PK FK REFERENCES permissions(id) ON DELETE CASCADE Target permission identifier.
created_at TIMESTAMPTZ NN DEFAULT CURRENT_TIMESTAMP Junction creation timestamp.

Table: user_roles

Junction table facilitating a many-to-many relationship mapping users to their configured roles.

Column Type Keys / Constraints Description
user_id UUID PK FK REFERENCES users(id) ON DELETE CASCADE Associated user identifier.
role_id UUID PK FK REFERENCES roles(id) ON DELETE CASCADE Associated role identifier.
created_at TIMESTAMPTZ NN DEFAULT CURRENT_TIMESTAMP Junction assignment timestamp.
